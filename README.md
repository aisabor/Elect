Global Candidate Popularity Demo

A front-end web application that simulates a global voting-style system where users can select candidates and see their popularity in real time.

This project is a non-real, educational demo designed to explore UI design, user interaction, and data handling concepts.

Features
Select and vote for candidates (demo only)
View popularity results
Simple interactive interface
Responsive design
 Disclaimer

This is a simulation project only and does not represent real elections or real-world voting systems. It is built purely for educational and development practice.
